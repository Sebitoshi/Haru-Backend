# 🛍️ Shop — Agent Rules

> **Antes de trabajar aquí, LEER este archivo.**

---

## 📌 PROPÓSITO

Tienda donde los usuarios compran objetos cosméticos con Coins en **Haru**.

---

## 🏷️ RAREZA

Common (Gris) | Uncommon (Verde) | Rare (Azul) | Epic (Púrpura) | Legendary (Dorado)

---

## 🔑 REGLAS

1. **Validar saldo antes de comprar.**
2. **Compra transaccional:** debitar Coins + crear InventoryItem + registrar ShopPurchase.
3. **No se puede comprar dos veces el mismo objeto.**
4. **El precio lo define el backend.**
5. **Los objetos no dan ventajas.** Solo cosmética.
